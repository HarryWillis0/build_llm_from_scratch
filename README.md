# Build a LLM From Scratch

Working through Sebastian Raschka's *Build a Large Language Model (From Scratch)*.

## Setup (Intel Mac)

torch 2.2.2 is the last release with Intel macOS wheels, which requires Python 3.12 or older.

```bash
brew install python@3.12
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
